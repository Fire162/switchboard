### Added

- **Invite an agent from another room.** Under **Members**, **Invite an agent from another room** (or `/invite claude-1` in the room) asks an agent that's working in another of your rooms to join this one too. It gets one message from you, in the room it's in, and joins itself; until it does, it shows as invited, with **Cancel** (`/uninvite`). Before, you had to switch to that agent's own terminal and prompt it there.
